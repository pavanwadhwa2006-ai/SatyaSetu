# Satyaseetu Internal Hackathon Demo Scenario

## Target
2–3 minute end-to-end demonstration.

## Story
1. Open Tender List.
2. Select primary real/public tender.
3. Show extracted requirements.
4. Analyze tender.
5. Show Requirement Matrix.
6. Open bidder list.
7. Select synthetic bidder.
8. Show uploaded documents.
9. Run verification.
10. Show GREEN/RED/YELLOW.
11. Open a GREEN requirement and show evidence.
12. Open a RED requirement and show failed rule.
13. Open a cross-document mismatch.
14. Open YELLOW Review Queue.
15. Officer resolves case.
16. Show Audit Trail.
17. Generate final compliance report.

## Final Message
"AI assists the Procurement Officer; it does not replace the Procurement Officer."

## Demo Rule
Do not manually edit database values during the demo. Start from a clean seeded scenario and let the application perform the workflow.
