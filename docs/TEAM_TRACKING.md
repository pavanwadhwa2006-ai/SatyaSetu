# Satyaseetu Team Tracking

## Working Rules
1. One phase at a time.
2. Every completed feature must work with actual internal data.
3. Do not replace working UI without a reason.
4. Do not commit secrets.
5. Do not hardcode final compliance results.
6. Do not claim unavailable government integrations.
7. Every AI output must have a defined purpose and schema.
8. Every compliance result should eventually be explainable through evidence and rules.

## Before Starting Work
Update:
- Phase
- Owner
- Task
- Dependencies
- Expected output

## Before Marking Done
Check:
- Works locally
- Tested with real internal data
- Error case handled
- API/database flow verified
- UI reflects actual backend response
- Documentation updated

## Team Roles
Suggested six-member split:
1. Frontend/Product UI
2. Backend/API
3. Database/Data
4. AI/NLP/RAG
5. Document Processing/Compliance
6. Integration/Security/QA/Demo
